# Lab 05 — تقييم الجودة واختبار التراجع

## نظرة عامة
يضيف هذا اللاب نظام تقييم بسيط لـ**Farah Hospital AI**.  
تتم مقارنة إجابات المساعد بمجموعة ثابتة من الحالات الصحيحة تسمى **Golden Set**، ثم يستخدم Regression Gate لمنع قبول نسخة جديدة إذا انخفضت جودتها بشكل كبير.

## الأهداف
- إنشاء Dataset ثابتة للتقييم.
- حساب جودة الإجابات تلقائيًا.
- اكتشاف الكلمات غير المؤكدة.
- مقارنة نسخة جديدة بالنسخة الأساسية.
- منع التحديث إذا تجاوز انخفاض الجودة الحد المسموح.

## Golden Set
تتضمن مجموعة التقييم أربع حالات:
1. سؤال المواعيد يجب أن يذكر خدمة المواعيد.
2. سؤال رسوم الاستشارة يجب أن يعيد **200 SAR**.
3. سؤال السجل الطبي يجب أن يذكر Patient Portal.
4. سؤال المطاعم يجب تصنيفه كطلب خارج خدمات المستشفى.

## التقييم الأساسي
الدالة `run_eval()` تتحقق من وجود القيمة المتوقعة داخل الإجابة.

نتيجة النسخة الأساسية:
- **100%**

## Simple Judge
الدالة `demo_judge()` تضيف تقييمًا بسيطًا:
- `3` — المعلومات المطلوبة موجودة بدون كلمات شك.
- `2` — المعلومات موجودة لكن معها كلمات مثل `I think`.
- `1` — المعلومات غير موجودة أو غير صحيحة.

## Regression Gate
تم تعديل سلوك سؤال رسوم الاستشارة في النسخة الجديدة، فأصبحت النتيجة:
- New Score: **75%**
- Baseline Score: **100%**
- Allowed Tolerance: **10 points**
- Gate Result: **BLOCKED**

بسبب انخفاض النتيجة بأكثر من الحد المسموح، تم رفض النسخة الجديدة.

## أهم ما تعلمته
يجب اختبار أنظمة الذكاء الاصطناعي باستمرار.  
استخدام Golden Set وRegression Gate يجعل الجودة قابلة للقياس ويساعد على اكتشاف أي تراجع قبل نشر النظام.

## ملاحظة
يوجد تعريف مكرر للدالة `run_eval()` داخل الـNotebook، لكن التعريفين متطابقان ولا يؤثران على النتيجة النهائية.
